# Scenic Route Music LLC

Official website and digital presence for **Scenic Route Music LLC** — a Washington State Service-Disabled Veteran-Owned Small Business (SDVOSB) providing live sound engineering, musical performance, rock band coaching, and government/commercial audio contracting.

---

## Architecture & 3 Dedicated Services

1. **Page 1: Live Sound & Audiovisual Production (`/` or `/live-sound`)**
   - Turnkey live sound engineering, Front-of-House (FOH) board mixing, feedback suppression, wireless microphone systems, and multi-zone PA routing for weddings, corporate events, and festival stages.
   - **Exclusive Add-On Bundles**: Direct integration with Luke Moore's live music performance packages.
   - Interactive AV quote request form.

2. **Page 2: Live Music by Luke Moore (`/live-music`)**
   - Americana Singer-Songwriter performing solo acoustic, vocal/bass duo, and full rock & roots band configurations.
   - **Interactive Song List & Repertoire Catalog**: Searchable and filterable catalog across Americana, Classic Rock, Folk & Country Classics, and Original Songs.
   - Direct performance booking form.

3. **Page 3: Music Lessons & Coaching (`/lessons`)**
   - Instruction across 5 core rhythm section instruments: **Guitar, Vocals, Drums, Bass, and Piano**.
   - Dual performance tracks: **Rock Band & Ensemble Dynamics** and **Acoustic Songwriting & Gigging**.
   - Lesson consultation & trial scheduler.

## Getting Started

### Prerequisites
- Node.js 18+ (or latest LTS)
- npm, pnpm, or yarn

### Development Server

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Quality Checks & Building

```bash
# Run ESLint checks
npm run lint

# Build for production
npm run build

# Start production server
npm start
```
